SWYNEX Intelligent Feature — AI Study Assistant

Project Overview

This is a beginner-level AI Study Assistant developed as part of my Artificial Intelligence internship learning with SWYNEX Technologies.

Features

- Answers student study questions using a Gemini AI model.
- Checks user input and handles empty questions.
- Handles API errors and retries temporary failures.
- Includes sample evaluation cases.
- Provides an interactive question-and-answer demo in Google Colab.

Technologies Used

- Python
- Google Colab
- Gemini API
- Google GenAI SDK

Evaluation

The project includes three sample evaluation cases. Basic keyword checks are used to compare answers against expected words. These checks are useful for practice but do not guarantee factual accuracy.

How to Run

1. Open the notebook in Google Colab.
2. Install the required Google GenAI package.
3. Enter a Gemini API key securely when prompted.
4. Run the code and ask study questions.

Security

Never share your API key publicly. Enter it securely when running the notebook.

Learning Outcomes

This project helped me practise AI model integration, Python functions, input validation, error handling, and basic evaluation.
